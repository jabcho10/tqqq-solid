# USD 솔리드 규칙서

작성일 2026-11-12 · 대상: USD (ProShares Ultra Semiconductors, 반도체 2배)

솔리드(TQQQ 최종안)를 USD에 맞춘 규칙이다. 모멘텀 필터는 쓰지 않고, **첫 매수 25%**와 **총 투입 상한 60%**를 더했다.
모든 주문은 종가 기준(LOC, MOC)이며, 주문가는 전날 종가로 계산한다.

---

## 1. 한눈에 보기

| 항목 | 값 |
| --- | --- |
| 매매 종목 | USD |
| 신호 지수 | 반도체 1배 지수 = USD 일간 수익률 ÷ 2 를 누적한 값 (백테스트와 동일) |
| 첫 매수 | 총자산 × 25%, 주문가 = 전날 종가 × 1.10, LOC |
| 추가 매수 | 매수1 = 전날 종가 × 0.995, 매수2 = 전날 종가 × 0.89, 각각 누적 매수액 × 25%, LOC |
| 최대 매수 횟수 | 첫 매수 포함 8회 |
| 매도 | 종가 ≥ 마지막 매수가 × 1.045 → 전량 LOC / 24거래일째 → 전량 MOC |
| RSI 엔진 | RSI(2) 역산, 매수 r=22 / 매도 r=25, 1회 = (사이클 기준 자산 × 30%) ÷ 2, 최대 2회, 10거래일째 MOC |
| 총 투입 상한 | 총자산의 60% |
| 모멘텀 필터 | 없음 |
| 수수료 (백테스트) | 매수·매도 각 0.07% |

**용어**
- **총자산** = 현금 + (메인 보유 수량 + RSI 보유 수량) × 전날 USD 종가
- **내림 / 올림** = 소수점 2자리 내림 / 올림
- **수량** = 금액 ÷ 주문가, 소수점 버림
- **N거래일째** = 첫 매수일을 0일로 센 거래일 수

## 2. 메인 엔진

### 2.1 첫 매수 (보유가 없는 날)
1. 기준 자산 = 전날 종가 기준 총자산. 이 값이 이번 사이클의 **사이클 기준 자산**이 된다.
2. 금액 = 기준 자산 × **25%**
3. 주문가 = 전날 종가 × 1.10 (내림), **LOC 매수**
4. 체결되지 않으면(종가 > 주문가) 다음 날 같은 방식으로 다시 주문한다. 기준 자산도 그날 다시 계산한다.
5. 체결되면 그날이 사이클 0일, 매수 횟수 1회.

### 2.2 추가 매수 (보유 중인 날)
매일 LOC 두 개를 낸다.

| 주문 | 주문가 | 금액 |
| --- | --- | --- |
| 매수1 | 전날 종가 × 0.995 (내림) | 지금까지 산 금액 × 25% |
| 매수2 | 전날 종가 × 0.89 (내림) | 지금까지 산 금액 × 25% |

- 종가 ≤ 매수1 → 매수1만 체결 (+1회)
- 종가 ≤ 매수2 → 둘 다 체결 (+2회)
- 매수 횟수가 8회에 도달하면 추가 매수 중단. 7회인 날은 매수1만 낸다.
- **24거래일째 되는 날은 매수 주문을 내지 않는다.**
- "지금까지 산 금액" = 이번 사이클 체결 금액 합계(수량 × 체결가, 수수료 제외).

### 2.3 매도 (전량)
- 매도가 = **마지막 매수가** × 1.045 (올림). 평단가가 아니라 가장 최근 체결가 기준.
- 종가 ≥ 매도가 → **전량 LOC 매도**
- 24거래일째 → **전량 MOC 매도**
- 같은 날 판단 순서: 24일 청산 → 1.045 매도 → 매수2 → 매수1
- 매도가 체결된 날은 매수하지 않는다.

### 2.4 사이클 종료
전량 매도되면 사이클이 끝난다. 다음 거래일에 그 시점 총자산으로 새 첫 매수를 낸다.

## 3. RSI 엔진

### 3.1 RSI(2) 계산 (신호 지수 기준)
- 첫 2일: AG, AL = 상승폭·하락폭의 단순평균
- 이후: AG = (전날 AG + 오늘 상승폭) ÷ 2, AL = (전날 AL + 오늘 하락폭) ÷ 2

### 3.2 내일 RSI가 r이 되는 지수 가격 P (장 마감 후 계산, C = 오늘 신호 지수 종가)
- P↑ = C − AG + AL × r / (100 − r)
- P↓ = C + AL − AG × (100 − r) / r
- P↑ > C 이면 P↑, P↓ < C 이면 P↓ 사용 (P 최소 0.01)
- 등락률 ch = P / C − 1 (하한 −33.3%)
- **USD 주문가 = 오늘 USD 종가 × (1 + 2 × ch)** (내림)

### 3.3 매매
| 구분 | 규칙 |
| --- | --- |
| 매수 | r = 22 가격. USD 종가 ≤ 매수가면 LOC 매수 |
| 1회 금액 | (현재 메인 사이클 기준 자산 × 30%) ÷ 2, 최대 2회 |
| 매도 | r = 25 가격. USD 종가 ≥ 매도가면 전량 LOC 매도 |
| 청산 | 첫 RSI 매수일을 0일로 10거래일째 전량 MOC |
| 판단 순서 | 10일 청산 → 매수 → 매도 |

- 메인 보유가 없는 날은 그날 첫 매수에 쓰는 기준 자산을 RSI 금액 기준으로 쓴다.
- RSI 물량은 메인 매수를 위해 팔지 않는다.

## 4. 총 투입 상한 60%와 현금 처리

1. 매일 주문 전에 **보유 평가액** = (메인 + RSI 보유 수량) × 전날 종가 를 구한다.
2. **매수 여력** = 총자산 × 60% − 보유 평가액 (0보다 작으면 0)
3. 그날 낼 매수 주문의 합계(주문가 × 수량 × (1 + 수수료))가 매수 여력과 현금 중 작은 값을 넘지 않게 줄인다.
4. 배분 순서: 첫 매수 또는 매수1 → 매수2 → RSI 매수. 남은 여력이 없으면 뒤의 주문은 내지 않는다.
5. 이미 보유한 물량은 상한에 맞추려고 팔지 않는다.
6. 미수·증거금 없음. 현금이 부족하면 있는 현금만큼만 산다.
7. 같은 날 매도 대금은 그날 매수에 쓰지 않는다.

## 5. 매일 주문 절차

장 마감 후(또는 다음 날 장 전)에 아래 순서로 계산한다.

1. 전날 USD 종가, 신호 지수 종가, 보유 현황(메인 수량·체결가·매수 횟수·사이클 시작일·누적 매수액, RSI 수량·매수 횟수·시작일), 현금을 확인한다.
2. 총자산, 보유 평가액, 매수 여력(60% 상한)을 계산한다.
3. **메인**
   - 보유 없음 → 첫 매수 LOC (25%)
   - 보유 중 → 24거래일째면 전량 MOC / 아니면 전량 매도 LOC(마지막 매수가 × 1.045) + 매수1·매수2 LOC
4. **RSI**
   - 보유 중 → 10거래일째면 전량 MOC / 아니면 (2회 미만이면) 매수 LOC + 전량 매도 LOC
   - 보유 없음 → 매수 LOC
5. 매수 주문 금액을 매수 여력과 현금 안으로 줄인다 (순서: 메인 → 매수2 → RSI).
6. 체결 후 보유 현황을 갱신한다. 매수 체결 시 마지막 매수가 갱신, 매도 체결 시 사이클 종료.

## 7. 감수할 위험과 주의

- **꼬리 위험**: 투입 60% 상태에서 하루 폭락(1987년형)이 오면 상한으로 막지 못한다. 계획상 최악 손실은 −50% 이상도 가정한다.
- **상한의 대가**: 합성 구간(2002~2007)과 2010년 시작 구간에서는 상한이 순정보다 약간 불리했다. MDD를 낮추는 대신 반등 수익을 일부 내주는 선택이다.
- **강세장 편향**: 실제 데이터(2007~)의 대부분이 반도체 강세장이다. 2016년 이후 성과(연 30%대)를 기대치로 쓰지 않는다.
- **파라미터는 고정**: 익절·매수율·MOC 일수 최적화는 반반 검증을 통과하지 못했다. 숫자를 바꾸지 않는다.
- **신호 지수**: 백테스트는 USD ÷ 2 대용 지수를 썼다. SOXX 등 다른 지수로 바꾸면 결과가 달라질 수 있다.
- **세금·수수료**: 사이클을 1년에 수십 번 실현하므로 양도세가 보유보다 불리하다. 수수료율이 높으면 성과가 줄어든다.
- **현금 운용**: 놀고 있는 현금(평균 60~70%)을 단기채에 두면 수익이 더해지지만, 백테스트에는 넣지 않았다. LOC 매수에 쓸 현금은 미리 확보해 둔다.
